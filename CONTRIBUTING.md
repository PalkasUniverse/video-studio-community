# 🐛 So meldest du einen Fehler / How to report a bug

[🇩🇪 Deutsch](#deutsch) · [🇬🇧 English](#english)

<a name="deutsch"></a>

## 🇩🇪 Deutsch

Du musst keine technischen Details erraten. Schreib einfach dazu, was du weißt. Auch Rückmeldungen zu Funktionen, die problemlos laufen, helfen! 😄

### Was ist passiert?

- Studio-Version und Setup- oder portable Version
- Windows-Version; bei einem Fehler auf der Website auch Browser und Version
- Was wolltest du machen?
- Welche Schritte führen zum Fehler?
- Was hast du erwartet und was ist tatsächlich passiert?
- Genaue Fehlermeldung, falls vorhanden
- Passiert es immer oder nur manchmal? Auch in einem neuen Projekt?

### Je nach Problem hilfreich

- **Import/Export:** Dateiformat, Codec soweit bekannt, Auflösung, Bildrate, Dauer, Export-Einstellungen, Hardware- oder Software-Encoding und Zielplayer. Keine Originaldatei nötig.
- **Untertitel/Karaoke:** Format und Ursprungsprogramm, bei VTT freies WebVTT oder YouTube VTT; beim ASS-/HTML-Import, ob es ein unveränderter Export des Lyrics Studios ist. Zeilen-, Wort- oder Zeichenzeiten und gewählter Karaoke-Stil.
- **Live Capture:** Monitor, Bereich, Fenster oder Kamera; betroffene Geräte; Mikrofon und/oder PC-Ton; Aufnahmequalität, FPS, SDR/HDR sowie Pause, Quellen- oder Gerätewechsel vor dem Fehler.
- **Darstellung:** Bildschirmauflösung, Seitenverhältnis, Windows-Skalierung und Anzahl der Monitore. Bei 32:9, 21:9 oder 16:10 bitte auch das Projektformat nennen.
- **Ton/Timing:** Audioformat, Dauer, Abtastrate und Bitrate soweit bekannt; welche Spur betroffen ist und ob Vorschau, Originalaufnahme oder Export das Problem zeigt.
- **Leistung:** Notebook oder Desktop, CPU, GPU und RAM soweit bekannt, gewählter Vorschaumodus, ungefähre Projektgröße und freier Speicherplatz.

Systemangaben sind freiwillig. Teile nur mit, was du vorher geprüft hast. Es wird nichts automatisch an einen Beitrag angehängt. Seriennummern, IP-Adressen oder vollständige private Dateipfade werden nicht benötigt.

### Bitte keine privaten Inhalte veröffentlichen

Dieses Repository und seine Discussions sind **öffentlich**. Bitte keine echten Lyrics, Audio-/Videodateien, Bildschirmaufnahmen mit privaten Inhalten oder Originalprojekte anhängen – auch nicht in ZIPs. Das gilt ebenso für Rückmeldungen per E-Mail.

Wenn ein Beispiel nötig ist, sichere dein Original und beginne in einem **neuen, leeren Projekt** mit erfundenen Platzhaltern. Nur sichtbaren Text im Original zu ersetzen reicht nicht zuverlässig: Importdaten, Wort-/Zeichenzeiten, Dateipfade oder der Verlauf können weitere Inhalte enthalten. Auch ASS und HTML können zusätzliche Studio-Daten enthalten.

Ein Screenshot mit Platzhaltern kann helfen. Prüfe sichtbare Fenster, Dateinamen, Kontaktdaten und Benutzernamen. Wenn der Fehler nur mit dem Original auftritt oder du dir bei einem Anhang unsicher bist, beschreibe ihn zunächst ohne Datei.

<a name="english"></a>

## 🇬🇧 English

You do not need to guess technical details. Just include what you know. Feedback about features that work well helps too! 😄

### What happened?

- Studio version and setup or portable edition
- Windows version; for website issues, browser and version too
- What were you trying to do?
- Which steps cause the issue?
- What did you expect, and what actually happened?
- Exact error message, if available
- Does it happen every time or only sometimes? Also in a new project?

### Helpful depending on the issue

- **Import/export:** file format, codec if known, resolution, frame rate, duration, export settings, hardware or software encoding and target player. No original file is needed.
- **Subtitles/karaoke:** format and originating program; for VTT, free WebVTT or YouTube VTT; for ASS/HTML, whether it is an unmodified Lyrics Studio export. Line, word or character timing and selected karaoke style.
- **Live Capture:** monitor, region, window or camera; affected devices; microphone and/or system audio; quality, FPS, SDR/HDR and any pause, source or device change before the issue.
- **Display:** screen resolution, aspect ratio, Windows scaling and number of monitors. For 32:9, 21:9 or 16:10, include the project format too.
- **Audio/timing:** format, duration, sample rate and bitrate if known; affected track and whether the problem occurs in preview, original recording or export.
- **Performance:** notebook or desktop, CPU, GPU and RAM if known, preview mode, approximate project size and free disk space.

System details are optional. Review anything you share. Nothing is automatically attached to your post. Serial numbers, IP addresses and full private file paths are not needed.

### Please do not publish private content

This repository and its Discussions are **public**. Do not attach real lyrics, audio/video files, screen recordings containing private information or original projects, including in ZIP archives. This also applies to email reports.

If an example is needed, save your original and start in a **new, empty project** using made-up placeholders. Replacing visible text in the original is not enough: import data, word/character timings, file paths or history may contain more content. ASS and HTML can also contain additional Studio data.

A screenshot with placeholders can help. Check visible windows, filenames, contact details and usernames. If the issue only occurs with the original or you are unsure about an attachment, describe it without a file first.
